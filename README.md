## About me

I study data science, but most of what I do outside class is building things: full-stack web apps, Flutter mobile apps, and projects focused on security.

I like owning a project end to end, from the database and API to the screen someone actually taps. Security is part of how I build from the start: password hashing, token-based auth, encryption, and checking my work against the OWASP Top 10.

What I'm focused on right now:

- Full-stack web with React, TypeScript, Node.js and PostgreSQL
- Mobile apps with Flutter, from idea to Google Play
- Application security and ethical hacking
- Machine learning fundamentals in Python
